# 预约常见问题（FAQ）

- 预约方式：小程序首页进入对应项目 → 选日期与场次 → 填写信息提交；也可直接点右下角「AI预约」浮窗，用自然语言告诉我「明天两点，两人，法兰绒深烘」即可帮你下单。
- 改约 / 取消：在「我的预约」里操作；或通过 AI 浮窗说「帮我取消 / 改到后天」。
- 人数限制：本店同时最多容纳 8 位客人，单次预约上限 2 人；超员请分两笔或提前电话 / vx 沟通当天预约情况。
- 迟到：只要在预约时间段内到店即可；若错过时间段，建议电话咨询店铺当前情况，一般情况下我们还能接待。
- 改期次数：当天有预约次数限制，您可以直接取消再重新预约，正常需求都能满足；开场后 30 分钟内仍可在小程序操作。有问题随时联系我们。
- 退改政策：开场前可以取消；改期也可自行在「我的预约」中操作。
- 指定店员：每天店员可能不同，只要该店员在店，可以指定由他 / 她为您冲煮。
- 费用与支付：预约本身免费，到店按所点单品结算；线上预约不涉及定金与预付，到店付即可。
- 包场 / 团建：团建本小店不太适合（位置太小）；包场请直接咨询我们，vx 与电话同号：19292757851。
- 加人：建议按预约人数到店，座位有限；如需加人可提前电话或 vx 沟通当天预约情况。
- 过敏 / 健康提示：
  - 咖啡豆来源：既有日本咖啡店的咖啡豆，也有自家煎焙的咖啡豆。
  - 外带：可外带没有太重味道的食品。
  - 饮酒：不建议孕妇饮酒（清酒含酒精）。
- 儿童 / 宠物：见店铺知识。
- 发票：到店结算后向店家索取。
- 联系方式：vx / 电话同号 19292757851（咨询教学、包场、当天预约情况等）。
