# 项目与菜单知识

小程序当前可预约项目（以可用性摘要中的「项目ID」为准，不要臆造）：

## 1. 法兰绒深烘咖啡
- 招牌：法兰绒滤布手冲深烘拼配，口感醇厚低酸，常见埃塞/哥伦比亚深烘。
- 适合：喜欢浓郁、巧克力可可调性的人群。
- 时长：单场约 1.5 小时；每日 10:00–18:00 分 5 个场次。
- 价格：以法兰绒深烘手冲为主，单杯约 50–120 元。
- 人数：本店同时最多容纳 8 位客人，单次预约上限 2 人。
- 教学 / 带做：是否含手冲教学可咨询店铺（vx：19292757851）。
- 咖啡豆：既有日本咖啡店的咖啡豆，也有自家煎焙的咖啡豆。
- 豆单系列：经典名店系列（搜集他店具深烘代表性的豆子）/ 自家煎焙系列（以深烘为主的自家煎焙）/ 经典复刻系列。
- 招牌单品：
  - 琥珀女王（经典特调）：相对原版做少糖处理，以天然蜂蜜替代炼乳与糖，不显苦、突出咖啡深度，适合不太容易吃苦又喜欢特调的人。
  - 野苦：深烘基底、风味强烈，适合咖啡老饕。
  - 黄油混合（经典特调）：致敬神户御影，黄油香气与咖啡深邃交融，用可食用咖啡杯盛装。

## 2. 清酒品鉴
- 招牌：多款日本清酒杯卖 / 品鉴组合，含熏、爽、醇、熟四类。
- 适合：想系统了解清酒、小酌慢饮的人群。
- 时长：单场约 2 小时；每日 18:00–22:00 分 2 个场次。
- 价格：因每周酒单不同，单杯多在 75–95 元之间。
- 人数：同上（本店最多 8 位、单次预约上限 2 人）。
- 选酒：由嚟酒师根据当周酒单为您选一款适合的清酒。

## 3. 法兰绒研习社
- 招牌：手冲教学 / 咖啡品鉴进阶体验，店员带做。
- 适合：想学冲煮、深度爱好者。
- 时长 / 价格 / 人数：以小程序「当前可约情况」实时展示为准。

## 4. 店铺菜单
- 单点：精品咖啡、清酒、轻食小点（以店内菜单为准）。
