# 项目与菜单知识

小程序当前可预约项目（以可用性摘要中的「项目ID」为准，不要臆造）：

1. 法兰绒深烘咖啡
   - 招牌：法兰绒滤布手冲深烘拼配，口感醇厚低酸，常见埃塞/哥伦比亚深烘。
   - 适合：喜欢浓郁、巧克力可可调性的人群。
2. 清酒品鉴
   - 招牌：多款日本清酒杯卖 / 品鉴组合，含熏爽醇熟四类。
   - 适合：想系统了解清酒、小酌慢饮的人群。
3. 法兰绒研习社
   - 招牌：手冲教学 / 咖啡品鉴进阶体验，店员带做。
   - 适合：想学冲煮、深度爱好者。
4. 店铺菜单
   - 单点：精品咖啡、清酒、轻食小点（以店内菜单为准）。

> 具体单品、价格、是否有套餐，以小程序「店铺菜单」页实时展示为准；被问到具体单品时引导用户去「店铺菜单」查看，不要报具体价。
