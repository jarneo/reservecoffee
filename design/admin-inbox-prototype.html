本次两处改动

  • 管理台顶部并排两卡：左「管理推送授权」（保留原有的一次性 / 已失效两态与续订按钮）、右「收件箱」（大字未读数，0 时照常显示只是转灰）。两卡等宽、等高。
  • 首页「进入管理端」移位：从页面底部大按钮，改为「预约项目」标题行右侧的小入口，仅管理员可见（role!=='none' 时渲染）。

收件箱能解决什么

✅ 不丢单：订阅额度用尽、短信没发、企微没装——只要写了库，管理员打开就一定看得到。
❌ 不实时：不是推送，不打开就不知道。实时提醒仍需企业微信 / 订阅消息 / 短信。

数据设计（已落地）

  • adminInbox：type(new|cancel) / resId / projectId / projectName / date / sessionStart~End / customerName / phone / count / note / byAdmin / createdAt / readBy[]
  • 写入点：createReservation、cancelReservation（失败静默，绝不阻断预约主流程）
  • 已读态：内嵌 readBy:[openid]；未读 = 库侧 readBy: _.neq(openid)，计数 / 筛选 / 分页同源
  • 云函数：getInbox（列表 + 单条详情 + 未读数）、markInboxRead（带 id=单条 / 不带=全部）
  • ⚠️ 曾考虑单独建 adminInboxRead 集合存 lastReadAt + readIds，但「未读筛选 + 分页 + 计数」无法在库侧同时成立，故改为内嵌数组
